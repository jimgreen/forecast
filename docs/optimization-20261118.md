# 2026-11-18 查询闭环与计算效率优化

## 交付内容

- 历史运行按运行编号恢复点位、对象和周期；支持返回该对象的最新结果，并兼容旧点位级运行。
- 气象和能源预测分别查询，避免较新的能源任务覆盖气象结果。接口返回实际运行编号和对象，便于追溯。
- 每个查询页面独立保存结果；切换筛选时取消旧请求，并阻止晚到响应覆盖新结果。CSV 导出全部查询行及点位、对象、运行编号、周期，使用 UTF-8 BOM。
- 输入页面只显示对应时段的实测值；查询失败或没有实测时显示空状态并禁止导出。能源质量统计复用当前结果，省去两次重复请求；弃电电量按 15 分钟弃电功率累计。
- 明细表自适应分页，支持上一页、下一页、末页和页码输入，保留全部 672 个周前点。查询选择器补充超短期 4 小时尺度。
- 训练按矩阵构建天气、时间、滞后和滚动特征；递推预测预分配数组，减少逐行 pandas 索引及扩容。保持天气到功率的递推次序、非负约束与容量边界。
- 模型缓存对全部相关历史数据和时间戳计算指纹，早期数据订正也触发重新拟合；同键并发请求共享拟合，不同键可并行，LRU 上限 16。
- 查询 SQL 直接选择指定或最新一条运行，再读取其结果，避免对所有运行做窗口排名。沿用 SQLite schema v6，无破坏性迁移。
